# Examples

`session-demo/` is a **fully synthetic** sample generated by `test/trace.test.mjs`.

It contains no real session, no personal data, and no network content: the events and the
streamed model response are fabricated by the test so the renderer can be checked end to end.
The demo deliberately includes a mid-turn model switch, so the 🔀 model-track rendering shows up.

| File | What it is |
|---|---|
| `00-格式说明.md` | the reading guide the plugin writes into every output directory |
| `index.md` | the turn index of one session |
| `turn-01.md` | the full first turn: overview, model track, timeline, prompts, headers, output, tools, per-request detail, wrap-up |

To generate your own real traces, install the plugin and run any DSH task; output goes to
`<session cwd>/dsh-traces` unless `outputDir` is configured.
